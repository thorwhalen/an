an.check_requirements

Diagnose system + Python deps that the various backends need.

Runtime-friendly: never raises; always returns structured per-tool status so the CLI (or a calling script) can decide what to do.

>>> result = check_requirements()
>>> isinstance(result, dict) and 'ffmpeg' in result
True
class an.check_requirements.ToolStatus(name: str, installed: bool, version: str | None = None, install_hint: str | None = None, detail: str | None = None)[source]

an.check_requirements.check_requirements() → dict[str, dict][source]

Return a per-tool status dict.
