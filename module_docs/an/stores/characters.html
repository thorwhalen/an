an.stores.characters

Characters store — JSON descriptor + sidecar folder per character.

A character’s meta.json carries name, art-style hint, default voice ref, slot map (which body parts exist), and optional defaults. Binary parts (SVGs, PNGs) are sidecars under the same directory.

class an.stores.characters.CharactersStore(root_dir: str | Path)[source]

Per-character directory store.

>>> import tempfile
>>> with tempfile.TemporaryDirectory() as d:
...     store = CharactersStore(d)
...     store['maya'] = {'name': 'Maya', 'voice_ref': 'maya-warm'}
...     store['maya']['name']
'Maya'
