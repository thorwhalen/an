an.audio.mac_say_tts

MacSayTTS — audible offline speech via macOS’s built-in say command.

Free, local, no API keys, no Python deps. macOS-only. The say binary ships with every macOS install since at least 10.4. Voices are listed by say -v '?' and can be passed as voice_id; common defaults: "Samantha", "Daniel", "Karen", "Alex".

Output is 16-bit little-endian PCM WAV at 22050 Hz so the rest of the audio pipeline (which prefers WAV) can read frames + duration directly.

>>> tts = MacSayTTS()
>>> tts.name
'mac_say'
