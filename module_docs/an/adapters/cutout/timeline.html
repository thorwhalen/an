an.adapters.cutout.timeline

Timeline: tracks of placed clips with absolute times and blend ramps.

A Timeline is a flat description of what plays when. It’s the canonical form passed downstream to the JS runtime in Phase 2B. Authoring composition trees from an.ir.compose (sequence/parallel/etc.) get flattened into a Timeline by compile_shot (see compile.py).

Evaluation semantics in Phase 2A:

  • For each track, identify all clips active at time t.

  • Each active clip produces a Pose.

  • Clips on the same track override each other in start-order (later wins).

  • Clips on different tracks merge with later-track override semantics (track order in the list determines priority — last track wins on conflict).

  • blend_in and blend_out ramps are recorded but not yet applied to pose values in 2A — the timeline produces the raw Pose and the renderer decides what to do with the ramps. Additive blending lands in 2B.

>>> from an.adapters.cutout.channel import Channel, Keyframe
>>> from an.adapters.cutout.clip import Clip
>>> ch = Channel("a", "x", [Keyframe(0.0, 0.0), Keyframe(1.0, 10.0)])
>>> clip = Clip("walk", duration=1.0, channels=[ch])
>>> tl = Timeline(duration=2.0, tracks=[Track("a", clips=[PlacedClip(clip, start_time=0.5)])])
>>> evaluate_timeline(tl, 1.0)[("a", "x")]
5.0
