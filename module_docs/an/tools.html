an.tools

User-facing utility functions, plus the SSOT list for CLI dispatch.

Each function here is meant to be callable from Python and from the shell via an tools <funcname>. Keep their signatures argh-friendly: positional args become required, defaults become optional flags.

an.tools.check() → str[source]

Print a status report of all backend system + Python deps.

an.tools.init(project_dir: str, name: str | None = None, force: bool = False) → str[source]

Create a fresh an project at project_dir.

project_dir: where to create the project (created if missing) name: project display name (defaults to the directory name) force: overwrite an existing scene.md

an.tools.render(project_dir: str, output_name: str = 'main', tts: str = 'offline', lipsync: str = 'offline') → str[source]

Render the project at project_dir to a single mp4.

project_dir: path to an an project (must contain scene.md / ir/scene.json) output_name: filename stem under output/ (default: “main”) tts: TTS provider — “offline” (silent) or “elevenlabs” (needs ELEVEN_API_KEY) lipsync: lip-sync provider — “offline” (deterministic) or “rhubarb”

(needs the rhubarb binary)

an.tools.sync(project_dir: str) → str[source]

Reconcile scene.md and ir/scene.json inside project_dir.

an.tools.validate(project_dir: str) → str[source]

Validate the scene at project_dir. Prints findings, exit 0 on pass.
