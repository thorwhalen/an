# character_gallery

Demonstrates the Phase 11 character authoring + SVG-texture rendering
pipeline end-to-end. The visible deliverable is a real cartoon —
`videos/cartoon.mp4` — produced by `an render` using two procedurally-
generated characters and the same Pixi runtime any production scene
uses.

## Run

```bash
python examples/character_gallery/build.py
```

What it does:

1. Generates two **offline** characters (`maya`, `charlie`) into
   `cartoon/assets/characters/` via `an.characters.new_character()`.
   Offline because the procedural mouth animation works on those —
   DiceBear avatars suppress the mouth overlay (see
   `SESSION_HANDOFF.md` §3 for the rationale).
2. Validates each character (parts present, 9-shape mouth set, pivots).
3. Runs the silhouette test pairwise. With identical body geometry the
   IoU is ~1.0 across pairs — that's the test working. Distinct body
   geometry would lower the score.
4. Writes per-character `preview.html` viewers (visemes + idle anim).
5. **Renders `cartoon/scene.md` to `videos/cartoon.mp4`** via
   `an render --parallel auto`. This is the demo: two SVG-textured
   characters speaking with lip-sync over a park backdrop, two shots
   (hold + push_in), 9 seconds.
6. Builds `index.html` embedding the cartoon at the top with links to
   each per-character preview.

## What's where

```
character_gallery/
├── build.py                          # the orchestrator
├── cartoon/
│   ├── scene.md                      # 2-shot scene with dialogue
│   └── assets/characters/{maya,charlie}/   # generated by build.py
├── videos/
│   └── cartoon.mp4                   # checked in (~100 KB); the demo deliverable
└── index.html                        # built by build.py; gitignored
```

## Equivalent CLI invocation

```bash
# Produce the characters
an character new maya --seed maya-warm --offline --out-dir cartoon/assets/characters
an character new charlie --seed charlie-bingo --offline --out-dir cartoon/assets/characters

# Inspect them
an character validate maya --out-dir cartoon/assets/characters
an character silhouette maya --other charlie --out-dir cartoon/assets/characters
an character preview maya --out-dir cartoon/assets/characters --open-browser

# Render the cartoon
an render cartoon --parallel auto
```

## Notes

- The cartoon reuses the same Pixi runtime as `examples/park_bench_cartoon`.
  Phase 11b's SVG-texture path is what makes `head.svg` (the procedurally-
  generated avatar) appear instead of an ellipse.
- `cartoon/output/` and `cartoon/.an/` are gitignored along with the
  generated character assets.
- Re-running `build.py` regenerates everything from scratch (`overwrite=True`).
